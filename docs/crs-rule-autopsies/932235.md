## Rule family (from the comments above the rule)

932230 (prefix + 2–3 letter commands), **932235 (prefix + longer known commands)**,
932250/932260 (same without prefix), 932236–932239 (stricter, PL2/PL3).
Raising the paranoia level adds siblings; it does not change 932235.

## One-variable experiments (JSON `comment`, route `/api/Complaints/`)

| `comment` | 932235 | Matched data |
| --- | --- | --- |
| `link ?utm_source=mail in the footer` | **match** | `=mail ` |
| `link ?utm_source=mail` (end of text) | no match | — no delimiter after `mail` |
| `link ?utm_source=email in the footer` | no match | `email` is not in the command list |
| `?utm_source=mail&x=1` | **match** | `=mail&` |
| `please mail me` | no match | no prefix |
| `x;mail me` / `x; mail me` | **match** | `;mail ` / `; mail ` |
| `x=mailx y` | **match** | `=mailx ` (mailx is listed too) |

All three parts — prefix, command word, delimiter — must be present. A pasted
URL supplies the prefix (`=`) and the delimiter (space or `&`) by accident.

## Possible false-positive causes

Pasted URLs whose parameter values are command names (`=mail`, `=find`,
`=more`, `=time`), and free text after `;`.

## Safest tuning point

Runtime exclusion **1010**: only rule 932235, only `ARGS:comment`, only
`POST /api/Feedbacks`. Not a threshold change and not `SecRuleRemoveById`.
